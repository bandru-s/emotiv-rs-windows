One row per EEG channel, decrypted in the page by the same code emotiv-raw runs — no Cortex service or EMOTIV Launcher involved. Every row is mean-removed and scaled to its own peak over the window; the figure after the name is that peak. Smoothing draws a moving average over a dimmed copy of the raw trace. Drawing happens in a worker on an OffscreenCanvas, so the main thread is left to the Bluetooth it cannot delegate. Needs a Web Bluetooth browser — Chrome or Edge — on localhost or HTTPS. Close the EMOTIV Launcher first: a headset accepts one connection at a time.
